# Scriptboard Help

Scriptboard helps writers and creative teams move from a screenplay to a production-ready visual plan. Import a draft, organize the story, develop characters and locations, and render a storyboard while keeping the script as the source of truth.

## Start with a project

- [Create a project](/scriptboard/getting-started/create-project) and name the workspace.
- [Import a script](/scriptboard/getting-started/import-script) or paste a draft into the editor.
- Review detected characters, locations, and scene boundaries before generating anything.

## Build the visual plan

- [Script workspace](/scriptboard/workspace/script)
- [Characters and locations](/scriptboard/workspace/characters-and-locations)
- [Storyboard](/scriptboard/workspace/storyboard)
- [Magik and Context](/scriptboard/workspace/magik-and-context)

## Work with a team

Invite collaborators, set their permissions, and review project activity from [Share and permissions](/scriptboard/collaboration/share-and-permissions).

## Need help?

If a generation or import fails, start with [Troubleshooting imports](/scriptboard/troubleshooting/imports-and-pdfs) or [Troubleshooting images](/scriptboard/troubleshooting/images-and-generation). When contacting support, include the project name, action, approximate time, and the visible error message. Never include API keys.
