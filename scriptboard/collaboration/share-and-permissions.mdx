# Share and permissions

Open project settings to invite collaborators by email. Choose the smallest role that fits the work:

- **Viewer** can read the project and review visual assets.
- **Editor** can edit the script and creative workspace.
- **Owner** controls project settings, collaborators, billing context, and deletion.

Owners can change a collaborator's role or remove access. Invitations and permission changes are recorded in project activity. Invitees receive an email notification when access changes.

## Shared with me

Projects someone has shared with you appear in **Shared with me**. The empty state should only appear when there are no incoming projects; your own projects remain in **My projects**.
