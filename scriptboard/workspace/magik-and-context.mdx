# Magik and Context

The contextual bars keep assistance close to the work without covering the script.

## Magik

Use the three actions in the Magik bar to scan the draft, continue a chapter, or explore an ending. Select existing text for rephrasing and error review. Suggestions appear in the script with a distinct tint and can be accepted or dismissed.

## Context

Ask questions about characters, scenes, continuity, locations, or themes. Context retrieves relevant material from the current script before answering, so you can ask focused questions such as "Where has this location appeared before?" or "What does Mia know at the end of scene three?"

AI output is a working aid. Verify suggestions against the screenplay before accepting them.
