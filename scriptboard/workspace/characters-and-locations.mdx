# Characters and locations

Scriptboard can detect characters and locations from an imported screenplay. Treat detection as a starting point: rename entries, add characteristics, and describe the visual continuity you want to preserve.

## Character references

Add appearance, age, wardrobe, and story-specific details. You can provide inspiration images or a drawing reference. Character generation creates a portrait and a vertical T-pose reference so storyboard frames can reuse the same identity.

## Location references

Add location characteristics, atmosphere, time of day, and visual references. A scene heading can be tied to a location so storyboard prompts stay consistent.

## Review before generating

Generation uses credits. Check the descriptions and references first, then generate only the assets you need. Open any generated image to inspect it at full size.
