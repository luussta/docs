# Script workspace

The Script view is the source of truth for the project. Use it to edit scene headings, action, dialogue, parentheticals, transitions, and sound cues. Changes are saved automatically when you pause editing.

## Magik in the draft

Magik works as an in-context assistant. Select text to request a rephrase or error review, then accept or dismiss a change. Accepted edits are applied to the screenplay; generated chapter or ending text is inserted as normal script text with a subtle AI-origin indicator.

Use **Organize** when a scene has no clear title or location. Review the suggested location before applying it to the draft.

## Export

Use **Export** to choose a common document format or a traditional screenplay format. Review the exported file in your preferred writing or production software before delivery.
