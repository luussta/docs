# Profile and project data

Account settings let you update your name, profile picture, and plan. Project settings include collaborators, activity, export, and lifecycle controls.

Export a project before deleting it if you need an offline copy. Deletion controls are intentionally separated from routine editing, and destructive actions require confirmation.

Never paste provider API keys into scripts, feedback, or support messages. Store credentials only in the environment or secret manager configured for your deployment.
