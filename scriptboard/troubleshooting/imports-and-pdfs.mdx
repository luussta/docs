# Troubleshoot imports and PDFs

## "No GlobalWorkerOptions.workerSrc specified"

This usually means the PDF worker could not be loaded. Refresh the app, retry with a selectable-text PDF, and make sure the deployment serves worker assets. If the issue persists, try DOCX, TXT, Fountain, or Markdown and include the exact browser error when contacting support.

## Formatting looks wrong

Review scene headings, character cues, dialogue, and page breaks after import. Complex templates, scanned pages, and files exported from unusual screenwriting tools may need a cleanup pass in Script view.

## Import does nothing

Check the file type and size, confirm the rights checkbox, and retry from a stable connection. Keep the original file so support can reproduce the parser issue.
