# Create a project

1. Open Scriptboard and choose **New project**.
2. Enter a project name. Use a name your collaborators will recognize.
3. Upload a script or paste text into the import area.
4. Confirm that you have the rights or permission to use the uploaded material.
5. Choose **Create project**.

Scriptboard keeps the imported draft as the project source. You can add characters, locations, visual direction, and storyboard frames without losing the original text.

## Project cover

You can upload a custom cover from project settings. If you do not provide one, Scriptboard creates a gradient cover using the project name.

## After creation

Start in the Script view to check formatting and detected scenes. Then review characters and locations before generating reference images or storyboard frames.
