# Import a script

Scriptboard accepts common screenplay and document formats, including Fountain, Final Draft FDX, Fade In XML, RTF, HTML, Markdown, DOCX, selectable-text PDF, TXT, JSON, XML, and screenplay files such as `.fountain`, `.fdx`, `.fadein`, `.rtf`, `.docx`, `.md`, `.txt`, and `.pdf`.

## Import checklist

- Upload the original file whenever possible instead of a screenshot.
- Confirm the rights checkbox before submitting the file.
- Review the first scene, character names, dialogue, and page breaks after import.
- Correct any formatting issues before generating visual assets.

Selectable PDFs can be parsed as text. A scanned PDF that contains only images may need OCR before importing. If the importer reports a worker or parsing error, see [Troubleshooting imports](/scriptboard/troubleshooting/imports-and-pdfs).

## Formatting expectations

Scriptboard normalizes common screenplay conventions (scene headings, action, character cues, dialogue, parentheticals, transitions, and sound cues) while keeping the draft editable. Always proofread the normalized result before sharing or exporting.
